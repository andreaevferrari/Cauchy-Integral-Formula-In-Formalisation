# Definition — continuity

## Statement

> [!definition] Continuous
> Let $\Omega \subseteq \mathbb{C}$ and $f : \Omega \to \mathbb{C}$. Then $f$ is *continuous at* $z_0 \in \Omega$ if $\lim_{z \to z_0} f(z) = f(z_0)$ ([[def-limit-in-c|limit]]), and *continuous* if it is continuous at every point of $\Omega$. The same definition, read with $|\cdot|$ as the absolute value on the source, defines continuity of a function of a real variable.

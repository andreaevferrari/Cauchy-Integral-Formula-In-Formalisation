# [Mae84] Maehara — The Jordan curve theorem via the Brouwer fixed point theorem

**Ryuji Maehara**, *The Jordan curve theorem via the Brouwer fixed point
theorem*, American Mathematical Monthly **91** (1984), 641–643.

The proof this network carries. Its virtue is economy: one topological input,
the Brouwer fixed point theorem, and one consequence of it about rectangles,
from which the whole separation statement follows. No homology, no degree
theory, no covering spaces beyond the single covering that establishes
Brouwer itself.

# Definition — piecewise smooth path

The class of curves along which the integral below is defined. Piecewise is
what admits the boundary of a square or a triangle, which a single smooth
parametrisation would exclude.

## Statement

> [!definition] Piecewise smooth path
> A *path* is a [[def-continuity|continuous]] $\gamma : [a,b] \to \mathbb{C}$. It is *smooth* if $\gamma$ is continuously differentiable with $\gamma' \neq 0$, and *piecewise smooth* if $[a,b]$ splits into finitely many subintervals on each of which $\gamma$ is smooth. The path is *closed* if $\gamma(a) = \gamma(b)$, and *simple* if $\gamma$ is injective on $[a,b)$.

# Definition — positively oriented path

Orientation is not a detail: reversing it replaces the value of the integral
by its negative, so a formula that produces $f(w)$ for one orientation
produces $-f(w)$ for the other.

## Statement

> [!definition] Positively oriented
> A piecewise smooth simple closed path $\gamma$ is *positively oriented* if it is parametrised so that its [[def-inside-of-path|inside]] lies on the left as the parametrisation traverses it.

## Notes

> [!note]- Notes (click to expand)
> - The counter-clockwise circle $C[a,r]$ is positively oriented, which is why that orientation is the standing convention in [[def-circle-and-disks]].

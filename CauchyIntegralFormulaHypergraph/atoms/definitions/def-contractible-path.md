# Definition — G-contractible closed path

The special case of homotopy that carries the weight: a loop that can be
shrunk to a point inside $G$ encloses nothing that $G$ omits.

## Statement

> [!definition] $G$-contractible
> A closed path $\gamma$ in $G \subseteq \mathbb{C}$ is *$G$-contractible* if it is $G$-[[def-homotopic-paths|homotopic]] to a constant path. This is written $\gamma \sim_G 0$.
